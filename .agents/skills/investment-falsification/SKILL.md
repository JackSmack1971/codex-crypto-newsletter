# Investment Falsification

## Inputs and outputs

Input: explicit thesis, asset identity, horizon, supporting evidence, and permitted sources. Output: falsification memo with strongest contrary case, assumptions at risk, tests, and verdict on thesis robustness.

## Workflow

1. Restate the thesis and its necessary assumptions. 2. Seek the strongest relevant contrary evidence, including neutral/cash alternatives. 3. Test identity, catalyst, token economics, liquidity, and market-data dependencies as relevant. 4. Separate failed assumptions from unknowns. 5. State decisive follow-up tests and whether the thesis survives this review.

## Evidence and failure behavior

Evidence: traceable sources, counter-hypotheses, tested assumptions, and unresolved gaps. Failure: `BLOCKED` when no thesis is provided or source policy prevents required checks; never convert a single-model review into independent approval.

Use the shared [research evidence contract](../crypto-daily/references/research-evidence.md) for source permissions, evidence labels, and common failure handling.
