# Tokenomics Diligence

## Inputs and outputs

Input: identified token/project, supply schedules, unlock/emission sources, value-flow evidence, and horizon. Output: tokenomics table and dilution/value-capture assessment with unresolved conflicts.

## Workflow

1. Confirm token and relevant contracts. 2. Reconcile circulating, total, and maximum supply definitions. 3. Build dated unlock/emission schedule with source confidence. 4. Trace protocol value flows to token holders and distinguish mechanism from realized flows. 5. Summarize dilution, incentives, and counterevidence.

## Evidence and failure behavior

Evidence: primary documents or traceable data, dates, units, denominator definitions, calculation, and conflicting schedules. Failure: `INCOMPLETE` when supply definitions or value-flow links are unresolved; do not collapse uncertainty into a single dilution estimate.

Use the shared [research evidence contract](../crypto-daily/references/research-evidence.md) for source permissions, evidence labels, and common failure handling.
