## Release check

Before returning the edition check and record:

- Source policy and approved costs/credits; runtime capability is not authorization.
- Reproducible universe/sample counts, not copied historical workbook size.
- Regime confidence supported by actual breadth/volatility/correlations and acknowledged gaps.
- Weakness, short and neutral alternatives investigated or limitations disclosed.
- Every finalist identity/contract/instrument matched.
- DEX/Hyperliquid/contract/Dune/independent review COMPLETE, PARTIAL, BLOCKED or N/A with no invented execution/data.
- Protocol value flows mapped to candidate token.
- 7–21-day horizon or justified max 28-day exception with near-term invalidation.
- Supply, liquidity/notional, event chronology and reviewer gates non-compensable.
- Descriptive non-overlapping scores linked to evidence; missing factors incomplete.
- Verdict/decision consistent; self-review not independence and no ignored vetoes.
- Evidence/screening/decision persistence real or explicitly NOT PERSISTED.
- Meaningful no-pick newsletter and useful research questions with no unauthorized trade.

Critical failure: return PARTIAL INTELLIGENCE EDITION — NO INVESTMENT-CLEARED PICK, disclose blockers, preserve available evidence. Missing sources do not excuse fabricated closure. If no substantive market data is authorized/available, preserve the format with unavailable fields and a useful research-readiness/watch milestone edition rather than pretending to have current market findings.
